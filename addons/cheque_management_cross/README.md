# Enhanced Post-Dated Cheque Management

## Description

This module offers a robust solution for managing post-dated cheques within the Odoo ecosystem. Post-dated cheques are issued for a future date and may be subject to specific handling rules depending on the country. Unlike the default Odoo functionality, this module allows users to register and manage cheques with corresponding accounting journal entries.

## Features

- **Multi-Currency Support**: Seamlessly handle cheques in different currencies.
- **Proration on Invoice Payments**: Distribute cheque amounts across multiple invoices.
- **Credit Allocation**: Automatically apply any remaining cheque balance as credit to customer or vendor accounts.
- **State Tracking**: Easily transition cheques through various states: new, registered, paid, returned, deposited, bounced, done.
- **PDF Reports**: Generate detailed reports for tracking and auditing purposes.
- **User-Friendly Filters**: Quickly find cheques based on their current state.

## Installation

1. Download or clone this repository.
2. Place the module folder into your Odoo addons directory.
3. Update the module list in Odoo.
4. Install the module from the Apps menu.

## Usage

1. Access the Accounting module.
2. Navigate to the Cheques menu.
3. Register a new post-dated cheque by providing the necessary details.
4. Manage and track the cheque through its lifecycle.
5. Use filters to locate cheques in different states.
6. Generate PDF reports as needed.
