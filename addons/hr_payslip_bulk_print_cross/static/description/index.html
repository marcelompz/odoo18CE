Impresión Masiva de Recibos de Nómina

Selecciona varios recibos de nómina y los imprime en PDFs separados (formato MTESS Paraguay)

Características principales

  • Selección múltiple desde la vista de lista de Recibos de nómina.
  • Acción disponible también en Lotes de nómina (hr.payslip.run).
  • Generación de un archivo ZIP con un PDF por cada recibo, o un PDF consolidado.
  • Compatible con Odoo 18 Community y Enterprise.
  • Integración con el reporte de Paraguay (l10n_py_hr_payroll_report) si está instalado.
  • Reporte propio: Recibo de Pago - Formato MTESS (Ley 213/93).

Puntos de acción

  1. Lista de Recibos de Nómina ➜ menú Acción → Imprimir Recibos en Masa.
  2. Formulario de un Recibo ➜ botón Imprimir (Lote).
  3. Lotes de Nómina (Batches) ➜ botón Imprimir Recibos del Lote.
