Portal Detalles

Sistema de carga de listas de productos desde el portal web

v18.0.1.0.0

🚀 Funcionalidades Principales

Permite a los comerciales generar enlaces para que los clientes carguen listas de productos desde el portal web de Odoo

🔗 Configuración de Enlaces

Los comerciales pueden crear configuraciones de listas portal, asignar pedidos, clientes y generar enlaces únicos con tokens de acceso.

📝 Formulario Web

Formulario tipo tabla responsive que permite cargar múltiples productos con talles y categorías de manera intuitiva.

🔔 Notificaciones

Sistema automático de notificaciones por email al comercial cuando se envía una lista y al cliente cuando es procesada.

📊 Seguimiento

Control completo del estado de las listas con seguimiento de items aprobados, rechazados y pendientes.

🔐 Seguridad

Tokens únicos de acceso, validación de permisos, tokens CSRF y reglas de seguridad por grupos de usuarios.

📱 Responsive

Diseño adaptable a dispositivos móviles con Bootstrap 5 y experiencia de usuario optimizada.
