Product Variant Image and Price Changer

Mejora la experiencia de compra con cambio dinámico de imágenes y precios

🖼️ Gestión Avanzada de Imágenes

Permite asociar múltiples imágenes a cada variante de producto, ofreciendo a los clientes una vista completa de todas las opciones disponibles.

💰 Actualización Dinámica de Precios

Los precios se actualizan automáticamente cuando los clientes seleccionan diferentes variantes, proporcionando transparencia total en los costos.

🎯 Interfaz Intuitiva

Miniaturas clickeables que permiten a los usuarios cambiar fácilmente entre variantes con efectos visuales suaves y profesionales.

📱 Diseño Responsivo

Optimizado para dispositivos móviles y de escritorio, garantizando una experiencia consistente en todas las plataformas.

📦 Instalación

  1. Descarga el módulo desde la tienda de aplicaciones de Odoo
  2. Instala el módulo en tu instancia de Odoo 18
  3. Ve a Ventas → Configuración → Productos → Imágenes de Variantes
  4. Configura las imágenes para cada variante de producto
  5. ¡Disfruta de la nueva funcionalidad en tu tienda online!

⚙️ Configuración

Backend: En la vista de formulario de cada producto, encontrarás una nueva pestaña "Imágenes de Variantes" donde puedes:

  • Subir imágenes específicas para cada variante
  • Organizar el orden de las imágenes
  • Activar/desactivar imágenes según sea necesario

Frontend: Los clientes verán automáticamente:

  • Miniaturas de todas las variantes disponibles
  • Cambio instantáneo de imagen principal al hacer clic
  • Actualización automática del precio
  • Información de la variante seleccionada
